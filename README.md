## Industrial problem

As-cast grain size and dendrite arm spacing set downstream strength and toughness; weld and additive-manufacturing thermal histories produce microstructures a plant cannot afford to trial-and-error.

**Why it happens.** Grain growth and dendrite selection depend nonlinearly on the thermal gradient and cooling rate supplied by the process-scale model.

## Data (no plant data)

Open data only: PRISMS-PF benchmark cases (R22, open source) and the analytical grain-growth law `d^n - d0^n = Kt` (R24). Thermal fields come from C07, not from a plant. Evidence level A.

> The author cannot supply factory data. This project uses **only open datasets and
> credible peer-reviewed journals**. If this is a B-level case, the case report
> must contain the exact disclaimer from `CASES.md` §1 and must **never** claim
> plant validation.
